# Quanto custa? Quanto sobra?

Mini-aula interativa de Matemática para o 7º ano: contas de compras com multiplicação, soma e troco (Livro 1, Missão 14, Parte 2).

**Professor:** Thiago, de Matemática
**Escola:** E.E. Moacyr Amaral

## Acesse

https://thiago-spba.github.io/aula-7ano-missao-14/

## O que tem

- Recados sobre o Matific e a tarefa
- Mini-aula em 3 ideias
- 4 questões com a conta passo a passo e o porquê de cada alternativa

## Tecnologias

HTML, CSS e JavaScript em um único arquivo (`index.html`), hospedado no GitHub Pages.
